# GUIA DE DEMONSTRACAO

## Objetivo

- Demonstrar a V1 da Connekt Pay sem depender de módulos externos ainda não homologados.

## Roteiro sugerido

1. Login
   - Entrar com um usuário válido
   - Mostrar redirecionamento para o dashboard

2. Dashboard
   - Exibir KPIs
   - Mostrar visão geral da operação

3. Payment Links
   - Abrir a listagem
   - Criar um link
   - Mostrar status, referência do provider e URL

4. Checkout público
   - Abrir o link criado
   - Demonstrar o redirecionamento para o checkout hospedado pela MyGateway quando disponível

5. Transações
   - Exibir listagem
   - Abrir detalhes

6. Recebedores e KYC
   - Abrir Recebedores
   - Mostrar detalhe do recebedor
   - Navegar para aprovação de KYC

7. Financeiro interno
   - Abrir Ledger
   - Mostrar telas internas de repasses e antecipação sem acionar provider externo

8. Administração
   - Abrir painel administrativo
   - Mostrar Eventos, Conciliação e Auditoria

9. Configurações
   - Abrir Configurações
   - Mostrar Integrações / Provedor Financeiro

## Mensagem para módulos externos bloqueados

- Informar que a base interna está pronta, mas a ativação real depende de contrato/homologação da MyGateway.
- Não demonstrar sucesso externo em módulos ainda não homologados.
