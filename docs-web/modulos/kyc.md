# Módulo: KYC

## Objetivo

Organizar e aprovar informações/documentos necessários para validar recebedores e reduzir riscos operacionais.

## O que faz

- Centraliza solicitações de KYC e documentos
- Permite revisão e decisão (aprovar/rejeitar) quando aplicável

## Como utilizar (passo a passo)

1. Acesse a área **Admin → Aprovação KYC**
2. Selecione uma solicitação
3. Revise documentos e informações
4. Registre a decisão e acompanhe o status

## Fluxo (como o usuário usa)

- Recebedor cadastrado → envio de documentos → revisão → aprovação/rejeição → operação liberada conforme política

## Permissões

- Owner: permitido
- Admin: permitido
- Financeiro: bloqueado

## Observações

- Integração automática do KYC com o provedor financeiro é parte da próxima fase (quando aplicável).
