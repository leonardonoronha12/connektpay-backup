# Módulo: Integrações

## Objetivo

Gerenciar chaves e parâmetros de integração com sistemas externos e com o provedor financeiro.

## O que faz

- Centraliza a criação/gestão de chaves de integração (quando aplicável)
- Reúne informações necessárias para conectar a Connekt Pay a serviços externos

## Como utilizar (passo a passo)

1. Acesse **Configurações → Integrações**
2. Crie/gerencie chaves conforme a necessidade do ambiente (homologação/produção)
3. Quando aplicável, configure URLs necessárias para comunicação automática

## Fluxo (como o usuário usa)

- Ativar integração → criar chave → conectar serviço externo → validar funcionamento

## Permissões

- Owner: permitido
- Admin: bloqueado
- Financeiro: bloqueado

## Observações

- Integrações e parâmetros sensíveis devem ser gerenciados apenas por Owner.
