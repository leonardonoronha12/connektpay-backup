# Módulo: Planos

## Objetivo

Definir planos para assinaturas (valor e ciclo), que serão usados na criação de assinaturas.

## O que faz

- Lista planos existentes
- Permite criar e manter planos que representam ofertas recorrentes

## Como utilizar (passo a passo)

1. Acesse **Planos**
2. Crie um plano com nome e valor
3. Use o plano ao criar uma assinatura

## Fluxo (como o usuário usa)

- Definir planos → vender recorrência → acompanhar assinaturas e transações relacionadas

## Permissões

- Owner: permitido
- Admin: permitido
- Financeiro: bloqueado (não deve acessar telas de planos/criação)

## Observações

- Mantenha nomes de planos claros (ex.: “Mensal”, “Anual”, “Premium”).
